# Agent Guide for `streamflow-docker`

This document contains key architectural details, conventions, workflows, and developer guidelines for AI agents working in this repository.

---

## 1. Project Overview & Architecture

`streamflow-docker` is an end-to-end containerized stream processing and analytics pipeline built with **Kafka**, **Apache Spark**, **Apache Airflow 3**, **Streamlit**, and **Docker Compose**.

```
[Kafka Producer] ---> (Kafka Topic: retail_events) ---> [Spark Streaming Ingestion]
                                                                  |
                                              +-------------------+-------------------+
                                              |                                       |
                                     (Valid Records)                          (Invalid Records)
                                              v                                       v
                                     `data/raw/`                            `data/rejects/`
                                              |                                       |
                                    [Spark Batch Summary]                     [Reprocess Job]
                                              v
                                   `data/curated/daily_summary/`
                                              |
                                     [Streamlit Dashboard]
```

- **Kafka Broker**: Apache Kafka 4.3.1 (Dual-listener setup: `localhost:9092` for local host, `kafka:29092` inside Docker network).
- **Producer**: Ingests retail sales events into Kafka (`src/streamflow/producer.py`).
- **Spark Ingestion**: Real-time streaming job (`spark/jobs/streaming_ingest.py`) parses JSON, enforces schemas (`src/streamflow/schemas.py`), runs quality checks (`src/streamflow/quality.py`), and routes valid events to `data/raw/` and invalid events to `data/rejects/`.
- **Spark Batch & Reprocessing**:
  - `spark/jobs/daily_summary.py`: Aggregates raw sales into daily summaries, top items, and low-stock alerts in `data/curated/`.
  - `spark/jobs/reprocess_rejects.py`: Recovers and re-evaluates rejected events.
- **Airflow Orchestration**: Airflow 3 (`docker/airflow.Dockerfile`) schedules daily summaries and recovery workflows via DAGs in `airflow/dags/`.
- **Streamlit Dashboard**: Visualizes sales metrics and inventory alerts (`scripts/streamlit_dashboard.py`).

## 2. Dependency Management (`pip-tools`)

Dependencies are strictly managed using **`pip-tools`** to prevent version drift and conflicting sub-dependencies.

- **`requirements.in`**: High-level direct dependencies. **Edit this file to add or update libraries.**
- **`requirements.txt`**: Compiled, deterministic lockfile generated by `pip-compile`. **DO NOT edit manually.**
- **`pyproject.toml`**: Package metadata and optional dependency groups (`spark`, `airflow`, `dashboard`, `dev`).

### Commands
```bash
# Recompile requirements.txt after updating requirements.in
make compile-deps

# Sync local environment with compiled requirements.txt
make sync-deps
```

## 3. Directory Layout

| Directory | Purpose |
| :--- | :--- |
| `src/streamflow/` | Core Python package (`producer.py`, `schemas.py`, `quality.py`). |
| `spark/jobs/` | Spark PySpark scripts (`streaming_ingest.py`, `daily_summary.py`, `reprocess_rejects.py`, `smoke_test.py`). |
| `airflow/dags/` | Airflow DAGs (`streamflow_daily_summary.py`, `streamflow_reprocess_recovery.py`). |
| `docker/` | Docker Compose (`docker/compose.yml`) and container definitions. |
| `scripts/` | Streamlit dashboard (`streamlit_dashboard.py`), data generator (`generate_pregen_data.py`), and cleanup script (`cleanup_data.py`). |
| `data/` | Pipeline storage (`raw/`, `curated/`, `rejects/`, `checkpoints/`, `metadata/`). |
| `tests/` | Pytest test suite for schemas, quality checks, producer, and data cleanup. |

---

## 4. Key Makefile Commands

- **`make up`**: Starts all Docker Compose services (Kafka, Producer, Airflow, Spark).
- **`make down`**: Stops containers and cleans generated data.
- **`make clean`**: Purges `data/` subdirectories (`raw`, `curated`, `rejects`, `checkpoints`).
- **`make test`**: Runs cleanup and executes `pytest tests/`.
- **`make dashboard`**: Launches Streamlit UI on `http://localhost:8501`.
- **`make compile-deps`**: Recompiles `requirements.txt` from `requirements.in`.
- **`make sync-deps`**: Syncs active environment using `pip-sync`.
